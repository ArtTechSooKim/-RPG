영어 단어 학습 RPG 게임 기획 초안
1. 프로젝트 방향

목표:
영어 단어를 암기하는 과정을 RPG 플레이와 결합하여,
단순한 영어 학습 앱이 아니라 게임을 하다 보니 영어 단어를 외우게 되는 게임을 만든다.

개발 엔진: Unity
최종 플랫폼: 모바일 앱
기존 경험: Unity 게임 개발 + Expo 기반 앱 개발
초기 목표: 작은 규모의 게임을 빠르게 완성하여 재미와 수익화 가능성을 검증
장기 목표: 콘텐츠를 확장하여 실제 수익을 발생시키는 서비스로 발전
2. 핵심 컨셉
「영어 단어를 배우는 몬스터 RPG」

플레이어는 3마리의 몬스터를 고정 파티로 데리고 다닌다.

맵을 탐험하면서 영어 단어를 학습하고,

단어 학습 → 플레이 → 보상 → 몬스터 성장 → 새로운 지역 → 더 어려운 단어

의 순환을 만든다.

단순히 문제를 풀고 점수를 얻는 방식이 아니라,
영어 공부 자체가 RPG의 성장 시스템으로 연결되는 것이 핵심이다.

3. 맵 구성

오픈월드까지 만들 필요는 없음.

하나의 세계를 여러 지역으로 나누고,
지역마다 영어 난이도를 다르게 설정한다.

예시:

지역	난이도	특징
초원	Lv. 1	기본 영어 단어
숲	Lv. 2	중급 단어
폐허	Lv. 3	고난도 단어
고대 도시	Lv. 4	고급 단어
최종 지역	Lv. 5	종합 난이도

처음에는 800점 수준의 영어 어휘 지역 하나만 구현해도 충분하다.

이후 900점 수준 등으로 확장.

※ 실제 TOEIC 점수/문제를 직접 사용하는 것이 아니라 자체적인 영어 난이도 체계로 운영하는 방향.

4. 몬스터 시스템

플레이어는 3마리의 몬스터를 파티로 구성한다.

몬스터의 역할

예:

공격형
방어형
지원형

몬스터마다 능력치와 특성을 다르게 설정할 수 있다.

진화 시스템

몬스터가 단순히 레벨만 올라가는 것이 아니라,

게임에서 얻은 특정 재료/아이템을 사용하여 진화

하도록 만든다.

예:

탐험 → 재료 획득 → 몬스터 성장 → 진화 → 새로운 능력

이를 통해 플레이어가 영어를 공부할 게임 내 목표를 만들어준다.

5. 영어 단어 시스템

초기 버전에서는 영단어에 집중한다.

예를 들어 800 난이도 지역에 들어가면 해당 수준의 단어들이 등장한다.

단어 하나를 여러 단계로 관리

처음 만남

abandon
버리다, 포기하다

↓

학습

↓

복습

↓

숙련

↓

완전 숙련

이렇게 단어마다 숙련도를 갖는다.

플레이어가 자주 틀리는 단어는 다시 등장하도록 만들 수 있다.

6. 게임 플레이 루프

핵심은 이 부분.

기본 루프

① 맵 탐험

↓

② 몬스터/이벤트 발견

↓

③ 영어 단어 학습 또는 테스트

↓

④ 성공

↓

⑤ 경험치 / 게임 재화 / 진화 재료 획득

↓

⑥ 몬스터 성장

↓

⑦ 더 어려운 지역 해금

↓

⑧ 새로운 단어 학습

이 과정을 반복한다.

즉,

공부해야 게임을 하는 구조가 아니라
게임을 하다 보니 공부하게 되는 구조

를 목표로 한다.

7. TOEIC 문제는?

처음에는 TOEIC 문제 자체를 사용하지 않는다.

TOEIC의 실제 문제를 그대로 사용하면 저작권·상표 등의 문제가 발생할 수 있기 때문.

대신,

영어 단어 학습 게임

으로 독립적인 콘텐츠를 만든다.

향후 AI를 활용해서 자체 영어 문제나 예문을 생성하는 것도 가능하지만, 실제 서비스에서는 생성 콘텐츠의 품질과 권리 문제를 별도로 검수해야 한다.

9. 수익화

최종 목적은 게임을 만들어서 수익을 발생시키는 것.

가능한 수익 모델:

① 광고

무료 플레이 기반.

일반 광고
보상형 광고
광고 제거 결제
② 인앱 결제

게임 재화나 꾸미기 요소 등을 판매.

예:

몬스터 스킨
캐릭터 스킨
장식 아이템
게임 내 재화
추가 콘텐츠
③ 프리미엄 학습 콘텐츠

예:

고급 단어팩
특정 분야 단어팩
추가 지역
특별 몬스터
④ 구독

장기적으로 이용자가 확보되었을 때 고려.

예:

광고 제거 + 프리미엄 단어 콘텐츠 + 추가 학습 기능

10. 가장 중요한 차별점

단순한 영어 단어 앱이 아니라,

Duolingo 같은 학습 앱 + 몬스터 RPG

의 결합을 목표로 한다.

하지만 처음부터 모든 기능을 만들지 않는다.

핵심 질문

"영어 공부를 하려고 게임을 켜는가?"

보다

"게임을 하려고 켰는데 영어 단어를 계속 외우고 있는가?"

를 확인하는 것이 이 프로젝트의 핵심이다.
