## 2. 전투

- 파티 3마리 vs 적 1~3마리. 한 라운드 = **아군이 순서대로 [스킬 선택 → 단어 문제 → 결과]** 후 적 전원 행동
- **정답** → 스킬 발동. **3초 이내**면 크리티컬 ×1.5
- **오답 / 10초 초과** → 스킬 실패, 단어는 오답 노트로. (UI는 정답을 꼭 보여줘서 학습 순간으로 만든다)
- **기본기 = 영→한 (쉬움), 필살기 = 한→영 (어려움)** — 강한 기술일수록 어려운 문제
- **처음 보는 단어**는 '새 단어' 카드로 뜻을 먼저 보여준 뒤 영→한으로 출제
- 기절한 아군은 차례를 건너뜀. 회복 스킬로는 살릴 수 없음 (마을에서 회복)
- 보호막은 건 쪽의 다음 행동 차례가 오면 사라짐 → 방어형의 '책 방패'는 이번 적 공격을 막는 용도
- 적 AI: 스킬 무작위, 단일 공격은 무작위 대상, 회복은 체력 비율이 가장 낮은 아군

| 공식 | 값 |
|---|---|
| 데미지 | 위력 × 공격 / (공격 + 방어), ±10%, 최소 1 |
| 회복량 | 위력 + 공격/2 |
| 보호막 | 위력 + 방어/2 |
| 경험치 | Σ(적 기본 경험치 × 적 레벨) + **정답 수 × 2** — 파티 전원(기절 포함) 동일 지급 |
| 골드 | Σ(적 기본 골드 × 적 레벨) |
| 드롭 | 적마다 재료별 확률 |

## 3. 단어 숙련도

| 상황 | 결과 |
|---|---|
| 정답 + 처음 만남 | → 학습 |
| 정답 + 복습 시기 도래 | 한 단계 상승 |
| 정답 + 복습 시기 전 | 변화 없음 (몰아 풀기로 숙련도가 오르지 않게) |
| 정답 + 오답 노트에 있음 | 단계 유지, 오답 노트에서 빠짐 |
| 오답 | 한 단계 하락(최저 '학습'), 오답 노트, 즉시 출제 대상 |

복습 간격: 학습 5분 → 복습 1일 → 숙련 3일 → 완전 숙련 7일

**출제 우선순위**: ① 오답 노트 ② 복습 시기 된 단어 ③ 새 단어 (학습 중 단어가 12개 미만일 때) ④ 본 단어 중 숙련도 낮은 것.
최근 4문제에 나온 단어는 건너뜀. 4지선다 오답 보기는 같은 품사 우선, 뜻이 겹치는 단어(acquire/obtain)는 제외.

## 4. 몬스터 (임시 데이터)

| 아군 | 역할 | 기본기 (영→한) | 필살기 (한→영) | 진화 (Lv5 + 재료 3개) |
|---|---|---|---|---|
| 펜촉이 | 공격형 | 찌르기 | 잉크 뿌리기 (적 전체) | 깃펜기사 ← 빛나는 잉크 |
| 책껍질 | 방어형 | 몸통박치기 | 책 방패 (아군 보호막) | 백과거북 ← 단단한 표지 |
| 등불이 | 지원형 | 빛 구슬 | 치유의 빛 (아군 회복) | 지혜등불 ← 반짝 가루 |

| 적 | 출현 | 드롭 |
|---|---|---|
| 잉크 슬라임 | 초원, 던전 | 빛나는 잉크 40%, 단단한 표지 15% |
| 낙서 박쥐 | 초원, 던전 | 반짝 가루 40%, 빛나는 잉크 15% |
| 까먹깨비 | 던전 | 단단한 표지 60%, 반짝 가루 30% |

레벨업 필요 경험치 = 10 + 10 × 현재 레벨, 최대 Lv30. 진화하면 레벨 유지, HP 완전 회복.
