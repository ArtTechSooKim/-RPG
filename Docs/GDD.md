## 2. 전투

- 파티 3마리 vs 적 1~3마리. 한 라운드 = **아군이 순서대로 [스킬 선택 → 단어 문제 → 결과]** 후 적 전원 행동
- **정답** → 스킬 발동. **3초 이내**면 크리티컬 ×1.5
- **오답 / 10초 초과** → 스킬 실패, 단어는 오답 노트로. (UI는 정답을 꼭 보여줘서 학습 순간으로 만든다)
- **기본기 = 영→한 (쉬움), 필살기 = 한→영 (어려움)** — 강한 기술일수록 어려운 문제
- **처음 보는 단어**는 '새 단어' 카드로 뜻을 먼저 보여준 뒤 영→한으로 출제
- 기절한 아군은 차례를 건너뜀. 회복 스킬로는 살릴 수 없음 (마을에서 회복)
- 보호막은 건 쪽의 다음 행동 차례가 오면 사라짐 → 방어형의 '책 방패'는 이번 적 공격을 막는 용도
- 적 AI: 스킬 무작위, 단일 공격은 무작위 대상, 회복은 체력 비율이 가장 낮은 아군

| 공식 | 값 |
|---|---|
| 데미지 | 위력 × 공격 / (공격 + 방어), ±10%, 최소 1 |
| 회복량 | 위력 + 공격/2 |
| 보호막 | 위력 + 방어/2 |
| 경험치 | Σ(적 기본 경험치 × 적 레벨) + **정답 수 × 2** — 파티 전원(기절 포함) 동일 지급 |
| 골드 | Σ(적 기본 골드 × 적 레벨) |
| 드롭 | 적마다 재료별 확률 |

## 3. 단어 숙련도

| 상황 | 결과 |
|---|---|
| 정답 + 처음 만남 | → 학습 |
| 정답 + 복습 시기 도래 | 한 단계 상승 |
| 정답 + 복습 시기 전 | 변화 없음 (몰아 풀기로 숙련도가 오르지 않게) |
| 정답 + 오답 노트에 있음 | 단계 유지, 오답 노트에서 빠짐 |
| 오답 | 한 단계 하락(최저 '학습'), 오답 노트, 즉시 출제 대상 |

복습 간격: 학습 5분 → 복습 1일 → 숙련 3일 → 완전 숙련 7일

**출제 우선순위**: ① 오답 노트 ② 복습 시기 된 단어 ③ 새 단어 (학습 중 단어가 12개 미만일 때) ④ 본 단어 중 숙련도 낮은 것.
최근 4문제에 나온 단어는 건너뜀. 4지선다 오답 보기는 같은 품사 우선, 뜻이 겹치는 단어(acquire/obtain)는 제외.

## 4. 몬스터 (임시 데이터)

| 아군 | 역할 | 기본기 (영→한) | 필살기 (한→영) | 진화 (Lv5 + 재료 3개) |
|---|---|---|---|---|
| 펜촉이 | 공격형 | 찌르기 | 잉크 뿌리기 (적 전체) | 깃펜기사 ← 빛나는 잉크 |
| 책껍질 | 방어형 | 몸통박치기 | 책 방패 (아군 보호막) | 백과거북 ← 단단한 표지 |
| 등불이 | 지원형 | 빛 구슬 | 치유의 빛 (아군 회복) | 지혜등불 ← 반짝 가루 |

| 적 | 출현 | 드롭 |
|---|---|---|
| 잉크 슬라임 | 초원, 던전 | 빛나는 잉크 40%, 단단한 표지 15% |
| 낙서 박쥐 | 초원, 던전 | 반짝 가루 40%, 빛나는 잉크 15% |
| 까먹깨비 | 던전 | 단단한 표지 60%, 반짝 가루 30% |

레벨업 필요 경험치 = 10 + 10 × 현재 레벨, 최대 Lv30. 진화하면 레벨 유지, HP 완전 회복.

## 5. 저장 (세이브/로드)

- **자동 저장만** 있음 (저장 버튼 없음): 문제에 답할 때마다, 전투 결과 후, 앱이 백그라운드로 갈 때·종료될 때
- 앱을 켜면 **타이틀 화면**: 저장이 있으면 [이어하기](금색) + [처음부터], 없으면 [시작하기] 하나. 저장 요약 카드(지역 · 파티 · 발견한 단어 · 전투 수)
  - [처음부터]는 확인 창("되돌릴 수 없어요")을 거쳐 저장을 지우고 새 게임
  - 타이틀에서 시작하기 전에는 저장하지 않는다 (켜고 바로 끄거나, 저장을 지운 뒤 꺼도 빈 세이브가 생기지 않게)
- 필드에서는 첫 알림에 "이어하기 — 발견한 단어 N개, 전투 N승 N패"
- 저장 내용: 파티(종 id, 레벨, 경험치, HP), 골드·아이템, 단어별 학습 기록(숙련도, 다음 복습 시각, 오답 노트, 맞힌/틀린 횟수, **발견 시각**), 누적 전적
- 전투 도중 앱이 꺼지면: 그때까지 푼 단어 기록과 HP는 남고, 전투 자체는 없던 일이 됨. 전멸 상태로 저장됐으면 불러올 때 회복
- 안전장치: 임시 파일에 쓴 뒤 교체 + 직전 세이브를 `.bak`으로 보관. 세이브가 깨지면 백업에서 복구, 둘 다 깨지면 지우지 않고 `.corrupt_날짜`로 보관 후 새 게임
- 세이브에서 몬스터 종을 찾을 수 없으면(삭제·id 변경) 그 몬스터만 빼고, 파티가 비면 시작 몬스터로 채움 — **단어 학습 기록은 항상 유지**
- **저장 데이터 지우기**: 설정 화면(필드 오른쪽 [설정] 또는 타이틀 오른쪽 위) → 빨간 버튼 → 확인 창 [지우기] → 타이틀로
- **설정**(배경 음악·효과음 음량, 진동)은 세이브와 따로 기기에 저장 (PlayerPrefs) → 저장 데이터를 지워도 설정은 남음.
  소리는 아직 없어서 음량은 값만 저장. 진동은 오답일 때 휴대폰에서만
- 위치: PC는 `%USERPROFILE%\AppData\LocalLow\DefaultCompany\영단어RPG\save.json`, Android는 앱 전용 폴더.
  ⚠ 회사명·앱 이름·번들 ID를 바꾸면 저장 위치가 바뀌어 기존 세이브를 못 찾음 (출시 전에 확정할 것)

## 6. 단어 도감 (구현됨 — 사용자 아이디어, 2026-10-01)

단어를 몬스터 도감처럼 "발견해서 채우는" 구조. 전투 화면 상단의 [도감] 버튼으로 연다
(스킬 선택 중·결과 화면에서만. 문제 풀이·연출 중에는 잠김).

- **발견** = 한 번이라도 문제로 만난 단어 (맞히든 틀리든). 미발견은 "???"로 가려 표시
- 전투의 '새 단어!' 카드 = 도감 등록 순간 ("새 단어! 도감 등록 (37/100)")
- 목록: 번호 + 단어 + 숙련도 별 (학습 ★☆☆☆ ~ 완전 숙련 ★★★★), 숙련도별 행 색상
- 단어를 누르면 상세: 뜻, 품사, 예문, 별 등급, 맞힘/틀림 횟수, 다음 복습까지 남은 시간, 발견일
- 상단: 지역 완성률 바, "37 / 100 발견 · 완전 숙련 N개", 완성 보상 안내

**지역 완성 보상 (사용자 결정)**: 도감 100% → **지역 징표(기념물) + 골드**, 지역당 한 번, 자동 지급
(결과 화면에 "★ 초원 도감 완성!" 표시). 진화 재료는 도감 보상에 넣지 않고 **다른 경로**로 얻는다
(현재는 적 드롭, 이후 필드 보물상자·상점 등 — 아직 미구현).

| 지역 | 징표 | 골드 |
|---|---|---|
| 초원 | 네잎클로버 책갈피 (행운을 부르는 눌러 말린 네잎클로버) | 500 |

- 지역 정보는 단어장(WordDatabase)에 설정: regionId(세이브용, 바꾸지 말 것), regionName, 징표 아이템, 골드
- 새 지역 추가 절차: 단어 CSV 추가 → 단어장에 지역 정보·징표 지정 → 징표 아이템(종류 Keepsake) 만들기
  → `Refresh Game Database`. 빠뜨리면 RegionDataTests가 실패해서 알려줌
- 보상을 받은 뒤 콘텐츠 확장으로 단어가 늘어도 받은 징표·골드는 그대로 유지 (완성률 표시만 내려감)
- 보류: 발견 수 중간 마일스톤 보상 (10/25/50개 등) — 필요하면 추가

## 7. 필드 (탐험)

`Assets/Scenes/Field.unity` = 게임 시작 씬. 탑다운, 한 칸씩 이동(포켓몬식)

- **조작**: 화면 아래 가운데 방향 패드(누르고 있으면 계속 이동), 에디터에서는 방향키/WASD도 가능
- **풀숲(진한 초록)**: 한 걸음마다 12% 확률로 야생 몬스터 조우. 조우 직후 4걸음은 안전 (연속 조우 방지)
- 조우하면 화면이 번쩍이고 전투 화면이 필드 위에 덮인다. 승리 → [계속 탐험]으로 같은 자리 복귀
  패배 → 파티 회복 후 시작 위치(회복의 샘 앞)로 귀환, 페널티 없음
- **회복의 샘**: 부딪히면 파티 완전 회복 (마을이 생기기 전 임시 회복 수단)
- **보물상자**: 부딪히면 열림, 상자마다 한 번만 (세이브에 기록). **진화 재료를 얻는 도감 외 경로** (사용자 결정)
- 화면 위: 지역 이름, 도감 발견 수, 골드, [도감] 버튼 / 그 아래 파티 HP 바
- 위치는 자동 저장 → 다시 켜면 마지막 자리에서 시작

**맵 만들기**: 지역 에셋(`Assets/Data/Areas/*.asset`, FieldArea)의 map 칸에 글자로 그린다

| 글자 | 뜻 |
|---|---|
| `.` | 길 |
| `,` | 풀숲 (조우) |
| `#` | 나무 (막힘) |
| `~` | 물 (막힘) |
| `F` | 회복의 샘 (부딪히면 회복) |
| `E` | 진화의 제단 (부딪히면 진화 화면) |
| `S` | 상점 (부딪히면 상점 화면, 지역의 shop에 연결된 상점) |
| `B` | 보스 (부딪히면 보스전, 지역마다 하나, 한 번 이기면 끝) |
| `D` | 출입구 — 밟으면 다른 지역으로. 연결은 exits 목록에 위→아래, 왼→오른 순서로 대응 |
| `C` | 보물상자 — 내용물은 chests 목록에 위→아래, 왼→오른 순서로 대응 |
| `P` | 시작 위치 (하나만) |

모든 줄의 길이가 같아야 하고, 상자 수 = 내용물 수, 시작 위치에서 모든 상자·샘에 갈 수 있어야 함 (AreaDataTests가 검사).
상자 위치를 옮기면 새 상자로 취급된다(이미 연 기록은 위치 기준). 아트가 들어오면 Tilemap 팔레트로 그린 맵을 읽도록 바꿀 수 있음.

**초원 맵** (19×23): 아래쪽 마을(제단·샘·상점·시작) → 북쪽 풀밭 → 연못 지대 → 북쪽 끝 두 방 → 맨 위 동굴 입구(던전)

| 상자 위치 | 내용물 |
|---|---|
| 북동쪽 구석 | 단단한 표지 x2 |
| 북서쪽 방 | 빛나는 잉크 x2 |
| 가운데 풀밭 | 반짝 가루 x2 |
| 마을 위 풀밭 | 100 골드 |

진화에 재료 3개가 필요하므로 상자(2개) + 적 드롭으로 모은다.

## 8. 마을 (진화·상점)

초원 아래쪽 마을에 **진화의 제단**(샘 왼쪽)과 **상점**(샘 오른쪽). 둘 다 부딪혀서 연다.
창이 열려 있는 동안은 움직이지 않는다.

**진화의 제단**
- 파티 3마리의 진화 조건을 한눈에: "→ 깃펜기사   Lv5 · 빛나는 잉크 2/3" (충족 초록 / 부족 빨강)
- 버튼: [진화!] / 레벨이 부족해요 / 재료가 부족해요 / 최종 형태

- 결과: "★ 펜촉이가 깃펜기사로 진화했다! HP 50→63 공격 29→39 방어 13→20 / 새 기술: 잉크 폭풍"
- 레벨 유지, 재료 소모, HP 완전 회복, 자동 저장

## 9. 던전 · 보스

**지역 이동**: 출입구(D)를 밟으면 화면이 어두워졌다 밝아지며 다른 지역의 연결된 출입구 칸에 나타난다.
같은 씬에서 맵만 바꿔 그림. 도착 직후에는 되돌아가지 않고, 한 칸 벗어났다 다시 밟아야 이동.
마지막 지역·위치가 저장되어 다시 켜면 그 지역에서 시작 (지역은 GameDatabase에서 id로 찾음).

**잊혀진 서고** (던전, 17×24, 서고 테마)
- 초원 북쪽 동굴 입구 ↔ 서고 아래쪽 출입구
- 그림: 벽=책장, 조우 칸=흩어진 책장(종이), 물=잉크 웅덩이, 바닥=나무 마루
- 구조: 입구 → 책장 미로 → 회복의 샘 → 큰 열람실(보물상자 2개: 200골드, 반짝 가루 1) → 꼭대기 보스 방
- 조우 14%, 까먹깨비 Lv3~5 / 잉크 슬라임·낙서 박쥐 Lv2~4, 1~3마리
- 단어장: MVP는 난이도 하나라 초원과 같은 100단어 (2단계 단어장은 콘텐츠 확장 때)

**보스: 까먹대왕 Lv7** (까먹깨비들의 우두머리)
- HP 98 / 공격 32 / 방어 24 — 진화한 Lv6 파티 기준으로 약 5라운드(문제 15개 안팎)
- 기술: 망각의 안개(파티 전체), 깜빡 방망이(단일), 기억 흡수(자기 회복)
- 부딪히면 보스전 ("보스 출현! … 정답으로 맞서라!"). 지면 일반 패배와 같음 (파티 회복, 서고 입구로)
- 이기면: 경험치·골드 + **진화 재료 3종 각 1개 확정**, 보스 자리는 빛나는 펼친 책으로 바뀜, 다시 싸울 수 없음 (저장)
- 지역 데이터: boss(종·레벨). 맵의 B와 보스 지정이 맞는지, 출입구가 서로 왕복되는지 DungeonDataTests가 검사
