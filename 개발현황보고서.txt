 [확정된 결정 요약]
------------------------------------------------------------------
 - 전투   : 턴제, 스킬을 쓸 때마다 단어 문제. 정답=발동(3초 안이면 크리티컬), 오답/10초 초과=실패
            기본기는 영→한(쉬움), 필살기는 한→영(어려움)
 - 맵     : 탑다운 타일맵 + 풀숲 랜덤 조우. 맵은 글자로 그림 (GDD 7장)
 - 진화 재료: 적 드롭 + 필드 보물상자 + 마을 상점(60G) (도감 보상에는 넣지 않음)
 - 진화   : 진화의 제단에서, 버튼 두 번 (되돌릴 수 없어서 확인)
 - 화면   : 세로 고정
 - 숙련도 : 처음 만남 → 학습 → 복습 → 숙련 → 완전 숙련
            복습 간격 5분 → 1일 → 3일 → 7일, 틀리면 한 단계 하락 + 오답 노트
 - 기본값 : 4지선다, ScriptableObject 데이터, 임시 아트, 로컬 저장, 포획 없음, 패배 페널티 없음
 - 도감   : 발견=한 번이라도 문제로 만난 단어. 지역 완성 보상=징표(기념물)+골드, 진화 재료는 다른 경로
 - 저장   : 자동 저장만 (답할 때마다, 전투 후, 앱 내릴 때), 켜면 자동 이어하기
 - 미정   : 단어 출처, 게임 이름, 앱 번들 ID, 렌더 파이프라인(URP 전환 여부), 수익화
            ※ 회사명·앱 이름·번들 ID를 바꾸면 세이브 위치가 바뀜 → 출시 전에 확정
